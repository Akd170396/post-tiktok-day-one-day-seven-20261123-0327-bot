Entry for make.fun's "Day one, day seven" TikTok bounty: a short vertical video about the same tiny agent-built game on the day it was made and after a week of daily updates, posted publicly on TikTok. The program copies VIDEO.json, which names the video's TikTok address, to /output.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
